# Join Us Form V2

Built from Spandana V100 as the reference baseline, but the Volunteer page itself was redesigned rather than preserving the V100 form's weak visual treatment.

## Scope
- Reworked the public Volunteer page into a universal Join Us / People & Engagement form.
- Preserved existing Nav/Footer, UI primitives, API route family and Program data source.
- Added multi-association support: Volunteer, Professional/Specialist, Advisor/Mentor, Patron, Sponsor, Partner, Ambassador, Representative, Supporter/Well-wisher, Other.
- Added adaptive professional fields for business/entrepreneur, student and retired professional contexts.
- Added qualification, specialization, organization, role, experience, expertise and location fields.
- Kept contribution types separate from professional expertise and program interest.
- Kept program choices dynamically loaded from the existing Program system.
- Kept safeguarding and under-18 emergency contact validation.
- Expanded Admin review and CSV export to expose the new fields.
- No Connect QR system, Person master, ID-card system or WhatsApp automation was added in this build; those remain separate future phases.

## Important visual decision
V100 is treated as a functional reference, not as a design to blindly copy. The new page uses a cleaner, more professional information hierarchy suitable for volunteers and senior professionals alike.
